Method 033: WFCGS

Wave Function Collapse Grid Synthesis maps a 2D matrix of voices and chronological sections as a system of collapsing superpositions. Horizontal rules govern the transition of bars, while vertical rules establish the harmonic and contrapuntal relationship between Lead, Pad, and Bass.

Local Rule Definitions:
H(Pad_A) → Pad_B (Alternating cadences)
V(Lead_1) → Pad_B (High-tension vocal resolution)
V(Pad_A) → Bass_A (D-based alignment)
V(Pad_B) → Bass_B (C-based alignment)

Method SP-022: WTS

Wave Terrain Synthesis uses a 2D orbit trajectory to scan a 2D mathematical wave surface. For Project 045, the Lead track is rendered using a Lissajous orbit over a sine-product terrain, with dynamic scale modulation defining a vibrant, filter-like vocal sweep.

Terrain Equation:
z = f(x, y) = sin(π · x) * cos(π · y)

Lissajous Orbit:
x(t) = r(t) · sin(2π · f_0 · t)
y(t) = r(t) · sin(2π · 1.5 · f_0 · t)
