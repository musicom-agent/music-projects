# Musicom Agent

Repository purpose: documentation and handover for the Musicom composer agent.

This repo introduces the Musicom agent, stores composer skill documentation, research notes, session logs, and handover material for other agents.

## Repository boundaries

- Projects: `musicom-agent/music-projects`
- Agent docs and handover: `axelwiertz/musicom-agent`
- Core library/framework code, when needed: `musicom-agent/musicom` or dedicated framework repos

## Contents

- `skills/` — Musicom composer skills and supporting references.
- `docs/` — overview documentation and history.
- `handover/` — onboarding notes for other agents.
- `sessions/` and `session_logs/` — selected session artifacts.
- `composer-crew-framework/` — composer-agent framework documentation/prototype material, not project portfolio output.

## Operating rule

Do not store generated projects here. Put all project folders, audio, MIDI, dashboards, and project-local scripts in `musicom-agent/music-projects`.
