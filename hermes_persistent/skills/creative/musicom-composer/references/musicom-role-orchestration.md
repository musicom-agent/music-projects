# Musicom Framework Orchestration (CrewAI Roles)

This skill governs the coordination of the internal "Musicom Agents" (Theoretician, Melodist, Arranger) to ensure a consistent, multi-role compositional outcome.

## Agent Persona Definitions

### 1. Music Theoretician
- **Responsibility**: Tonality, Scale selection, Global Rules.
- **Core Intent**: Ensuring "Intervallic Tension" and mathematical relations between patterns.
- **Workflow**: Decides the 'Modal Window' (e.g., D Dorian) before the Melodist begins.

### 2. Melodic Composer (Melodist)
- **Responsibility**: Pitch DNA and Rhythmic DNA.
- **Core Intent**: Euclidean symmetry (E(k, n)) and memorable interval contours.
- **Workflow**: Generates a 'Seed Pattern' that remains consistent across the piece to maintain identity.

### 3. Arranger & Export Specialist
- **Responsibility**: Matrix Rendering, Counterpoint, Final Audio/MIDI Export.
- **Core Intent**: Layering and Balance.
- **Workflow**: Manages the interaction between roles (e.g., instructing the Bass to invert the Melodist's DNA).

## The Musical Matrix (Workflow Step)

All compositions must be planned in a Matrix format before rendering:
- **Phase 1**: Theoretician sets TONAL SCALE.
- **Phase 2**: Melodist provides DNA for LEAD.
- **Phase 3**: Arranger applies TRANSFORMATIONS (Inversion/Retrograde) for BASS/PADS.
- **Phase 4**: Batch rendering of all Matrix cells into a single Master Mix.
