# Musicom onboarding notes

Session-backed onboarding checklist for the Musicom framework.

- Verify access to the core logic repository and the creative output repository.
- Confirm the symbolic stack used for composition: music21, musicpy, mido.
- Confirm the audio/render stack: Pedalboard, numpy, FluidSynth, and a GM soundfont fallback.
- Initialize new projects from the canonical template directory.
- Keep local canonical artifacts separate from publication deliverables.
- Ensure the first run generates audio plus a dashboard for review.
