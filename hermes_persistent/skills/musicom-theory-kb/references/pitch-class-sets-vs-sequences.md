# Pitch Class: Sets vs. Ordered Sequences

This reference clarifies the distinction between Harmonic Space (Subsets) and Musical Time (Sequences) as explored in Project 011.

## 1. The PC Set (Harmonic Space)
- **Concept**: Unordered collection of Pitch Classes (e.g., {0, 4, 7}).
- **Usage**: Defining the "Palette" or "Universe" of allowed notes.
- **Compositional Value**: Determining the "Intersections" (Pivots) for smooth modulation.

## 2. The PC Sequence (Musical Time)
- **Concept**: An ordered tuple of Pitch Classes (e.g., (0, 7, 4, 0)).
- **Usage**: Defining the "Style" or "Path".
- **Stylistic Signatures (Example with {0, 4, 7})**:
    - **Baroque**: (0, 4, 7, 4, 0) - Constant arpeggiation, vertical focus.
    - **Minimalist**: (0, 0, 4, 4, 7, 7) - Rhythmic repetition, static sets.
    - **Modernist**: (0, 7, 16, 7) - Wide interval vectors, leaping across octaves.

## 3. Instrumentation Constraint Filter
- **Piano**: Short decay, high density allowed.
- **Strings/Winds**: Sustained, low density/open voicing required for clarity.
- **Rule of Thumb**: Assign the "Chromatic Signature" (the note that deviates from the base set) to the instrument with the highest frequency and lowest physical inertia.
