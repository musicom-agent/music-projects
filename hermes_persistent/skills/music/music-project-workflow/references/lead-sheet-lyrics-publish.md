# Lead-sheet lyric publication

Session lesson:
- When a generated score is too dense for Flat.io import, publish a simplified lyric-first lead sheet instead.
- Preserve title, meter, tempo, and melodic identity.
- Keep the canonical multitrack master local.
- Record the Flat.io URL in the project README and dashboard.

Use when:
- The project already has a strong MIDI master, but the cloud notation platform needs a readable publication copy.
- You need a quick publication artifact that is still tied to the lyric draft.
