# Disco Pattern Logic (4 Variants)

## Version 1: Classic Disco (1977-79)
**Key:** D minor | **BPM:** 120 | **Voices:** Drums, Bass, Strings, Brass

| Voice | Pattern | Density |
|-------|---------|---------|
| Drums | Four-on-the-floor kick + offbeat hi-hat + snare 2&4 + crash on section start | 100% |
| Bass | Syncopated octave jumps: root(1), octave(and-of-2), fifth(3), root(and-of-4) | 100% |
| Strings | Stabs on offbeats (and-of-1, and-of-3): 3rd+5th+7th chord | 50% |
| Brass | Hits on downbeats of bars 1,3: root+3rd+5th octave-up | 12% |

**Progression:** Dm7 → Gm7 → Dm7 → Am7 (i-iv-i-vi)

## Version 2: Funky Disco (1979-82) ★ BEST
**Key:** E minor | **BPM:** 118 | **Voices:** Drums, Bass, Guitar, Horns

| Voice | Pattern | Density |
|-------|---------|---------|
| Drums | Four-on-the-floor + 16th-note hi-hat (accented offbeats) + clap 2&4 + open hat and-of-4 | 100% |
| Bass | Slap bass: root(1), octave-slap(and-of-2), ghost(3), fifth(and-of-4) | 100% |
| Guitar | Wah-wah 16th-note strum: muted scratches + open chord on "and" of each beat | 100% |
| Horns | Syncopated stabs: beat 1, and-of-2, beat 4 — root+3rd+5th bright voicing | 75% |

**Progression:** Em7 → Am7 → Em7 → Bm7 (i-iv-i-iii)

**Why it won:** Highest density contrast (75% horns vs sparse rests), 16th-note hi-hat + slap bass + wah guitar = peak disco groove.

## Version 3: Orchestral/Salsoul Disco
**Key:** C major | **BPM:** 124 | **Voices:** Drums, Strings, Orchestra, Bass

| Voice | Pattern | Density |
|-------|---------|---------|
| Drums | Four-on-the-floor + 8th-note hi-hat + snare 2&4 + timpani roll on bar 4 (crescendo) | 100% |
| Strings | Sustained chords with 2-bar crescendo swell (60→85→80 volume) | 100% |
| Orchestra | Full hits on bars 1,3: bass+root+3rd+5th+root-octave (wide voicing) | 12% |
| Bass | Root-fifth-octave: root(1), root(and-of-2), fifth(3), octave(and-of-4) | 100% |

**Progression:** Cmaj7 → Fmaj7 → Cmaj7 → Dm7 (I-IV-I-ii)

## Version 4: Modern/Italo Disco (1983-86)
**Key:** A minor | **BPM:** 126 | **Voices:** Drums, Bass, Lead, Pad

| Voice | Pattern | Density |
|-------|---------|---------|
| Drums | Electronic: tight kick + 16th-note closed hat + clap 2&4 + open hat and-of-4 | 100% |
| Bass | Arpeggiated 16th-note: root-3rd-5th-7th-5th-3rd-root-3rd (8-note cycle) | 100% |
| Lead | Sequenced 8th-note: root-5th-3rd-7th pattern | 100% |
| Pad | Sustained chord with sidechain pumping: loud between kicks, quiet on kicks | 100% |

**Progression:** Am7 → Dm7 → Am7 → Em7 (i-iv-i-v)

## Key Techniques

### Shuffle vs. Straight
- **Classic/Funky:** Shuffle feel (long-short eighth notes, 2:1 ratio)
- **Orchestral/Modern:** Straight 8th/16th notes (electronic precision)

### Bass Patterns
- **Syncopated octave jumps:** root → octave → fifth → root (Classic)
- **Slap bass:** root → octave-slap → ghost-note → fifth (Funky)
- **Root-fifth-octave:** root → root → fifth → octave (Orchestral)
- **Arpeggiated:** 16th-note chord-tone cycle (Modern)

### Density Contrast
- **High contrast** (Funky): 75% horns with 25% rests = punchy
- **Low contrast** (Modern): 100% all voices = wall-of-sound
- **Sparse accents** (Classic/Orchestral): 12% brass/orchestra = dramatic hits

### Progression Patterns
- **i-iv-i-vi:** Classic minor blues-influenced
- **i-iv-i-iii:** Funky minor with relative major hint
- **I-IV-I-ii:** Orchestral major with secondary dominant
- **i-iv-i-v:** Modern minor (Andalusian cadence variant)
