# Repository Boundaries

## `musicom-agent/music-projects`

Use for Musicom projects only:

- numbered project folders: `NNN-project-name/`
- MIDI, MusicXML, audio renders, stems
- project analysis, notes, dashboards
- project-local generation scripts
- portfolio `index.html`

## `axelwiertz/musicom-agent`

Use for agent documentation and handover only:

- Musicom agent introduction
- composer skill docs and references
- onboarding/handover notes for other agents
- session logs and research notes
- framework documentation/prototypes

## Future work rule

When creating or updating a composition project, commit it to `musicom-agent/music-projects`.
When documenting agent behavior, skills, or handover, commit it to `axelwiertz/musicom-agent`.
